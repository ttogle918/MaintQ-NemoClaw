---
description: 진행 중인 작업 상태를 저장해 다음 세션에서 이어갈 수 있게 합니다. 사용법 /checkpoint
---

현재 작업 상태를 `docs/sprints/sprint-{N}-wip.md` 에 저장합니다.

1. `docs/sprints/` 에서 현재 스프린트 번호 N과 진행 중인 태스크 ID를 확인한다.
2. `sprint-{N}-wip.md` 가 없으면 새로 만들고, 있으면 덮어쓴다.
3. 아래 형식으로 작성한다:

```markdown
# Sprint {N} WIP — {MQ-XXX}
**저장 시각**: YYYY-MM-DD HH:MM
**상태**: 진행 중

## 완료한 하위 할일
- [x] ...

## 남은 하위 할일
- [ ] ...

## 현재 작업 중인 파일
- `경로/파일명` — 무엇을 하고 있었는지

## 검증 상태
- 회귀 스위트: (통과 / 미실행 / 실패 N건)

## 다음 세션에서 이어할 작업
1. ...

## 막혔거나 결정이 필요한 사항
- (없으면 생략)
```

저장 후 경로를 알려주세요.
