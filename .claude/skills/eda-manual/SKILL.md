# 매뉴얼 EDA 워크플로우

대상: `data/raw/` 안의 매뉴얼 PDF (iG5A 완전본, S100)

## 절차

1. PDF 기본 정보: 페이지 수, 용량, 텍스트 레이어 존재 여부 (pdfplumber로 텍스트 추출 시도 → 실패 시 스캔본으로 판단하고 비전 경로 보고)
2. 보호기능/에러코드 챕터 위치 특정 (목차 검색: "보호 기능", "고장", "트립", "Trouble")
3. 에러코드 표 구조 분석:
   - 열 구성 (코드/명칭/원인/조치)
   - 병합 셀, 셀 내 줄바꿈 여부
   - pdfplumber `extract_tables()` 결과와 원본 페이지 비교
4. 에러코드 총 개수 집계 (기종별)
5. 두 기종 간 동일 표기 코드 목록 추출 (OL, OC 계열 등)
6. 안전 경고문 패턴 수집 (위험/주의 표기, 콘덴서 방전 등) → safety-guardrail 스킬의 인용 소스
7. 결과를 `data/analysis/manual_eda.md`로 저장

## 산출물 형식

```markdown
# 매뉴얼 EDA 결과
## 기본 정보 (기종별 표)
## 에러코드 표 구조 (스크린샷 대신 추출 샘플 3행 포함)
## 추출 전략 결정: pdfplumber 파서 / camelot / 비전 모델 중 택1 + 근거
## 동일 표기 코드 목록
## 리스크: 추출 실패 예상 지점
```

## 주의

- `data/raw/` 파일을 수정하거나 이동하지 말 것 (읽기 전용)
- 표 추출 정확도가 90% 미만이면 비전 모델 경로를 권고하고 사람 결정 대기
- 추출 전략은 사람 승인 후 확정 (TODO_직접할일.md의 결정 대기 항목)
