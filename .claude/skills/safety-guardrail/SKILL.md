# 안전 가드레일 규칙

MaintQ가 다루는 인버터/PLC는 감전·화상 위험이 실재하는 장비다. 잘못된 조치 안내는 인명 사고로 이어질 수 있다. 아래 규칙은 협상 불가.

## 규칙

1. **안전 문구는 매뉴얼 근거 필수** — 안전 경고를 생성할 때 반드시 매뉴얼 페이지 인용을 포함. 매뉴얼에 없는 안전 절차를 창작하지 말 것
2. **위험 작업 키워드 등장 시 SAFETY 블록 필수** — 다음 키워드가 포함된 절차 안내에는 예외 없이 안전 경고 삽입:
   - 커버/덮개 개방, 내부 점검, 단자대, 배선, 절연 측정, 콘덴서, 통전, 활선
3. **기본 안전 경고 최소 세트** (매뉴얼 페이지와 함께 인용):
   - 전원 차단 후 내부 콘덴서 방전 대기 (대기 시간은 매뉴얼 명시값 사용, 임의 단축 금지)
     — **확정 명시값(사람 승인 2026-07-18): "10분 이상 + 테스터로 직류 전압 방전 확인"**.
     근거: iG5A 표준본 p.4, iG5A 트러블슈팅 p.6, S100 p.2 (PDF 물리 페이지 기준, D26).
     "5분" 등 축소 표기는 규칙 위반
   - 활선 상태 측정·접촉 금지
   - 자격 있는 작업자 수행 원칙
4. **AI 단독 판단 금지 원칙 유지** — "매뉴얼 기준으로는 ~"라는 프레임 유지, 단정적 지시어("그냥 열어서", "바로 만져서") 금지
5. **안전 문구 최종본은 사람 승인** — prompts.py의 안전 관련 문구를 확정할 때 TODO_직접할일.md에 검수 항목으로 추가하고 사람에게 알릴 것

## 코드에 적용할 때

- 안전 경고는 일반 응답 텍스트에 섞지 말고 구조화된 필드(예: `safety_warnings: []`)로 분리 → 프론트의 SAFETY 컴포넌트가 렌더
- eval의 "안전 경고 누락 0건" 지표가 이 규칙의 검증 장치 — 규칙을 완화하는 코드 변경은 금지
