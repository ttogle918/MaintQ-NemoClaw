# 잔가곡선 (residual_curve) — 목업 공식과 한계 실증

- 생성: `data/build_residual_curve.py` (자동 생성 문서 — 직접 편집하지 말 것)
- 생성일: 2026-08-09
- 결정: **D74**(목업 정률 공식 · D72 supersede) · D65(추정치 고지 강제) · D19(원본 읽기 전용)
- D72 에서 유지되는 것: **연차 버킷 6종 격자 · 평활 금지 · 카테고리 원본 바이트 · D65 고지**

> **이 곡선은 목업이다.** 실거래·호가 어느 쪽에서도 값을 가져오지 않았다.
> 법정 기준내용연수를 앵커로 한 **명시적 가정의 정률 감가 공식**이며, 시장 시세가 아니다.
> 이 값을 인용하는 모든 출력은 D65 의 추정치 고지를 함께 실어야 한다.
>
> **호가 데이터(중진공 장터)를 값 원천으로 쓰지 않는 이유는 §4 에 실측으로 남겼다.**
> 요약: 호가는 연차가 아니라 기계 규격이 지배해서 감가를 식별할 수 없다.

## 1. 곡선 (목업) — `residual_curve.json` 의 값

전 카테고리 동일 값이다. 카테고리 축은 **조인 키로만 존재**한다(이유 §2-5).

| age_bucket | 대표연차 | 취득연도 범위 | residual_ratio |
|---|---:|---|---:|
| `0-2` | 1 | 2024 ~ 2026 | **0.9170** |
| `3-5` | 4 | 2021 ~ 2023 | **0.7071** |
| `6-10` | 8 | 2016 ~ 2020 | **0.5000** |
| `11-15` | 13 | 2011 ~ 2015 | **0.3242** |
| `16-20` | 18 | 2006 ~ 2010 | **0.2102** |
| `21-30` | 25 | 1996 ~ 2005 | **0.1146** |

- 카테고리 7종 × 버킷 6종 = **42행**
- 취득연도 범위는 기준연도 2026 기준. 격자 밖(`age > 30`)은 행이 없다 — 소비 측은 `21-30` 로 클램프하거나 하한 0.1 를 쓸 것.

## 2. 공식과 파라미터 — **왜 이 값인가**

```
residual(age) = max( (1 - r) ** age , FLOOR )
r             = 1 - RESIDUAL_AT_LIFE_END ** (1 / N)
```

| 기호 | 값 | 무엇인가 | 성격 |
|---|---:|---|---|
| `N` | 8 | 법정 기준내용연수(제조업 기계장치) | **법령 — 미검증** |
| `RESIDUAL_AT_LIFE_END` | 0.5 | N 년 시점 잔가율 | **가정** |
| `r` | 0.0830 | 연 정률 상각률 (유도값) | 유도 |
| `FLOOR` | 0.1 | 잔존율 하한 | **가정** |
| (참고) 세법 잔존율 | 0.05 | 세법 상각률표 유도 관행 | 참고 곡선 전용 |

### 2-1. 상수를 박지 않고 유도한다

`declining_rate(N, residual_at_end)` 가 `r` 을 계산한다. 이 유도식은 세법 정률법 상각률표의
유도식과 같다 — `residual_at_end=0.05` 를 넣으면
N=8 → 0.3123, N=10 → 0.2589 로
상각률표의 **0.313 / 0.259 와 일치**한다. 즉 식 자체는 검증 가능하다.

### 2-2. `N = 8` — 법정 기준내용연수 ⚠ 미검증

제조업 기계장치의 기준내용연수를 8년으로 두었다(내용연수범위 6~10년의 중앙).
**이 값은 법령 원문과 대조되지 않았다.** 근거 문서(`법인세법 시행규칙` 별표)는
`data/rules/laws/` 수집 파이프라인이 `fetch_status:"PENDING"` 상태이므로,
원문이 확보되면 **가장 먼저 재검증해야 할 파라미터**다. 값이 바뀌면 곡선 전체가 바뀐다.

### 2-3. `RESIDUAL_AT_LIFE_END = 0.50` — 세법 0.05 를 그대로 쓰지 않은 이유

세법 관행(N 년 시점 잔존율 5%)을 그대로 넣으면 곡선이 이렇게 된다.

| age | 세법 정률 (r=0.3123) | 목업 (r=0.0830) |
|---:|---:|---:|
| 1 | 0.6877 | 0.9170 |
| 4 | 0.2236 | 0.7071 |
| 8 | 0.0500 | 0.5000 |
| 13 | 0.0077 | 0.3242 |
| 18 | 0.0012 | 0.2102 |
| 25 | 0.0001 | 0.1146 |

**age 20 에서 세법 곡선은 0.0006 다.** 그런데 실데이터는 20~30년 설비가 여전히 시장에
올라오고 호가된다는 것을 보여준다 — 집계 5종에서 `age 21-30` 매물이 911건 이고,
`'머시닝센터'` 의 `21-30` 호가 중앙값은 3,600만원이다(§4-2).
**"20년이면 사실상 0"은 과세 목적의 조기 상각 유인이지 시장 사실이 아니다.**

그래서 목업은 법정 내용연수를 **가치가 0 이 되는 시점이 아니라 절반이 되는 시점**으로
재해석한다. 이것은 **검증된 시장 사실이 아니라 명시적 가정**이다. 다만 두 가지를 만족한다.

1. **존재 사실과 모순되지 않는다** — 위 실측이 지지하는 것은 "오래된 설비도 무시 못 할 값에
   호가된다"는 **존재** 명제뿐이다. 기울기(감가율)는 실측이 말해주지 못한다(§4).
2. **격자 전 구간에서 판정력이 남는다** — 세법 곡선을 쓰면 `6-10` 이후가 전부 하한에 붙어
   `assess_repair_value` 의 verdict 가 연차를 구분하지 못한다. 이건 데이터 주장이 아니라
   **도구 요구사항**이다.

### 2-4. `FLOOR = 0.10`

설비가 고철·중고부품으로서 갖는 최소 회수가치의 자리표시자다. 과거 기업회계 관행의
잔존가액 10% 를 차용했다(**가정 — 근거 문서 미확보**).
현재 파라미터에서 하한이 실제로 구속하는 구간은 **age >= 27** 이므로
격자 대표연차(최대 25)에는 적용되지 않는다. 즉 격자 값은 전부 정률식 원값이다.
하한은 **격자 밖 연차를 조회하는 소비 측을 위한 방어선**으로만 존재한다.

### 2-5. 카테고리별 `N` 을 두지 않은 이유 — 카테고리 축의 정보량은 0

**단일 `N` 을 쓴다. 따라서 전 카테고리의 `residual_ratio` 가 동일하다.**

- 법정 기준내용연수는 **업종별**로 정해지는데, 이 카테고리는 중고 장터의 **매물 분류축**이라
  업종 코드로 매핑되지 않는다. 카테고리별로 다른 `N` 을 주면 그 차이 자체가 근거 없는 가정이 된다.
- 실데이터로 카테고리 차이를 추정할 수도 없다 — 그게 §4 의 결론이다.
- 그래서 카테고리 축은 **`(category, age_bucket)` PK 와 조인을 성립시키기 위해서만** 존재한다.
  카테고리별 차등이 필요해지면 그것은 **새 근거와 새 결정**이 필요한 일이다.

- 반대로 절삭유 펌프를 억지로 `'일반산업'` 으로 분류하면 **잘못된 분류가 데이터에 심긴다.**
  카테고리 축은 지금 정보량이 0이지만 **미래에 진짜 카테고리별 곡선이 들어올 때의 조인 키**이고,
  그때 이 오분류는 조용히 오판가로 바뀐다. 값이 아니라 **분류가 자산**이다.

- 표기 변종(`'환경 / 설비'`, `'공조/냉각/유공압'`, `'고무 / 플라스틱'` 등)은 **넣지 않았다** —
  같은 뜻의 두 문자열을 둘 다 조인 키로 두면 시드에서 어느 쪽을 쓰는지가 우연에 맡겨진다.
- 시드가 쓰지 않는 2종(`'가공기계'`·`'전기전자계측'`)은 남겨 둔다 — 자산이 늘 때 조인 키가
  없어서 다시 오분류하는 것을 막는다. 행 추가 비용이 0이므로 뺄 이유가 없다.

## 3. 한계

1. **목업 공식이며 실거래가와 무관하다.** 값의 출처는 데이터가 아니라 §2 의 가정 3개
   (`N`, `RESIDUAL_AT_LIFE_END`, `FLOOR`)다. 그중 `N` 만 법령 근거를 가지며 그마저 미검증이다.
2. **호가지 실거래가 아니다.** 유일하게 참조한 실데이터(중진공 장터)조차 매도 희망가이며
   성사가가 아니다. 그마저 값 원천이 아니라 한계 실증으로만 쓴다(§4).
3. **연 1회 스냅샷.** 원본 파일이 연말 1회 공개되므로 시세 변동을 추적할 수 없다.
4. **신품가 분모가 아니다.** `residual_ratio` 는 **취득원가 대비 비율**로 정의된다
   (`book_value ≈ acquisition_cost × residual_ratio`). 취득원가를 모르는 자산에는 쓸 수 없다.
5. **age 2~4 구간은 실측 표본이 아예 없다**(§4-1). 목업 공식은 이 구간에도 값을 내지만,
   그 값은 **공식의 외삽이지 관측이 아니다.**

### 4-2. 2단 — `카테고리2` 층화로도 우상향이 사라지지 않는다

"신형 매물은 소형기기, 구형은 대형기계"라는 구성 편향 가설을 검정했다.
세부분류를 고정하면(오염 제거 후 표본 3,741건 기준) 사라져야 하는데, 사라지지 않는다.

### 4-3. 3단 — 동일 `모델명` 안에서 연차-가격 상관이 사실상 0

규격을 가장 강하게 고정하는 방법은 **같은 모델끼리 비교**하는 것이다.
모델명별로 age·가격의 평균을 뺀 뒤(모델 고정효과 근사) 상관을 구했다.

| 카테고리2 | 모델 그룹 | 관측 | **모델 내 상관 r** | (참고) 단순 상관 r | n |
|---|---:|---:|---:|---:|---:|
| `머시닝센터` | 33 | 128 | **-0.17** | +0.13 | 494 |
| `프레스` | 12 | 56 | **-0.08** | +0.23 | 183 |
| `절단절곡기` | 22 | 196 | **-0.04** | +0.06 | 390 |

- 감가가 존재한다면 **강한 음의 상관**이 나와야 한다. 실제 모델 내 상관은 `|r| <= 0.17` 로
  사실상 무상관이고, 모델을 고정하지 않은 단순 상관은 오히려 **양수**다(규격 효과).
- 조건: 같은 모델명이 2건 이상이고 연차가 서로 다른 그룹만 사용.

### 4-4. 결론

**중고 매물 호가는 연차가 아니라 기계 규격(용량·크기)이 지배한다.** 규격 대리변수가 데이터에
없어 층화로도 회귀로도 감가를 식별할 수 없다. 억지로 단조 감소를 만들면 그것이 바로 D65·D72 가
금지한 "없는 정확도"다. 그래서 **값 원천을 목업 공식으로 바꾸고(D74), 이 분석은 근거로 남긴다.**

실데이터를 버린 게 아니다 — **실데이터가 무엇을 말할 수 없는지를 기록한 것**이다.

## 5. 산출물 스키마 — `data/extracted/residual_curve.json`

```jsonc
{
  "_status": "...", "generated_at": "...", "method": "...",
  "parameters": { "statutory_life_years": 8, "declining_rate": 0.083, ... },
  "disclosure": "...",     // D65 고지 문구
  "rows": [                // ← DB §17 residual_curve 시드 입력
    {
      "category": "환경  설비",  // 원본 바이트 그대로 (공백 2칸)
      "age_bucket": "11-15",     // 0-2|3-5|6-10|11-15|16-20|21-30
      "residual_ratio": 0.3242,  // max((1-r)**대표연차, FLOOR)
      "n_samples": null, "p25_ratio": null, "p75_ratio": null, "base_n": null,
      "source": "법정 기준내용연수 8년 기반 정률법 추정 (목업) — 실거래 데이터 아님 [...]"
    }
  ]

```

- ⚠ **`n_samples`·`base_n`·`p25_ratio`·`p75_ratio` 는 전부 `null` 이다.** 목업 공식에는 표본이
  없으므로 숫자를 채우면 거짓말이 된다(D74).
  → **`05_DB_SCHEMA.md` §17 의 `n_samples INTEGER NOT NULL`·`base_n INTEGER NOT NULL` 은
  nullable 로 바꿔야 한다.** MQ-601a 의 DDL 변경 필요 사항이다.
