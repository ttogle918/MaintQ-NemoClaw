## 에러코드 표 구조 + 추출 샘플

**S100 문제 해결 표 (p.416, 열 4개: 키패드 표시 | LCD 표시 | 고장 상태 | 내용):**

```
| oct | Over Current1 | Latch | 인버터 출력 전류가 정격 전류의 200% 이상일 때 발생합니다. |
| ovt | Over Voltage  | Latch | 직류부 회로의 전압이 규정 값 이상일 경우 발생합니다. |
| gft | Ground Trip*  | Latch | 인버터 출력 측에 지락이 발생하여 규정 값 이상의 전류가 흐르면 발생합니다. |
```

**iG5A 트러블슈팅 표 (p.22, 키패드 표시 셀은 7-세그먼트 이미지 → 텍스트 추출 시 빈칸):**

```
| (이미지␀) | 과전류  | Latch | 인버터 출력 전류가 정격 전류의 200% 이상일 때 발생합니다. |
| 원인: 부하의 관성(GD2)에 비해 가/감속 시간이 짧다 → 조치: 가/감속 시간을 길게 설정 |
```

**구조 특성 (extract_tables 관찰):**
- 병합 셀·다단 레이아웃 탓에 `extract_tables()`는 빈 셀(␀)·열 어긋남이 빈번 (특히 iG5A 표준본 통신 표는 27열로 파편화)
- 반면 `extract_text()`는 3문서 모두 읽기 순서·내용이 깨끗함 — **행 단위 규칙 파싱이 표 추출보다 신뢰도 높음**
- 셀 내 줄바꿈 다수 (원인/조치가 불릿 여러 개) → 원인·조치는 JSON array로 분해 필요 (스키마와 일치)

## 동일 표기 코드 목록 (D6 "같은 코드, 다른 의미" 실증 재료)

두 기종 교집합 **12종**: `BX` `ETH` `EXT` `FAN` `GFT` `LVT` `NTC` `OC2` `OCT` `OHT` `OVT` `POT`

- 의미 차이 예시(추출 후 상세 확정): **FAN** — iG5A는 냉각팬 이상 트립 단일 / S100은 Fan Trip·Fan Warning·FAN Exchange 3단 분화. **LVT** — iG5A 저전압 단일 / S100은 Low Voltage(Level)와 Low Voltage2(Latch, 운전 중) 구분. 심각도(severity) 매핑도 기종별 상이 (S100은 Latch/Level/Fatal/Warning 분류가 명시돼 있어 severity 컬럼의 직접 소스가 됨)

## 추출 전략 결정 (제안): **pdfplumber 텍스트 규칙 파싱 (하이브리드)** — 사람 승인 대기

| 경로 | 판단 |
|---|---|
| pdfplumber `extract_tables()` 단독 | ✗ 병합 셀·다단에서 열 정합 붕괴 빈번 |
| camelot | ✗ 같은 계열 한계 + 의존성 추가 대비 이득 없음 (텍스트 레이어가 이미 깨끗) |
| 비전 모델 전면 도입 | ✗ 과설계 — 스캔본 아님. 단 아래 iG5A 12.1 검증 보조로는 후보 |
| **`extract_text()` 행 단위 규칙 파싱 + extract_tables 보조** | ✓ **채택 제안** |

기종별 파이프라인:
1. **S100**: p.416~421 문제 해결 표에서 키패드 표시(텍스트)·LCD 표시·고장상태·내용·원인/조치 직접 파싱. p.309~310 일람표에서 severity(래치/레벨/Fatal/경보) 보강
2. **iG5A**: 코드 텍스트가 표에 없음(7-세그 이미지) → **통신 챕터(p.195·198) 비트명 20종 ↔ 보호기능 한글명 매핑 테이블**을 만들어 조인. 원인/조치는 트러블슈팅 p.22~29 + 표준본 12.2에서 파싱. **매핑 테이블은 사람 검수 필수** (기존 TODO "related_parts 검수"와 같은 단계에서)
3. 추출 결과는 `data/extracted/error_codes.json` — 코드별 `model, code, error_name, severity, causes[], actions[], manual_page(물리)` + 파싱 실패 항목은 `_unparsed` 목록으로 분리해 수작업 대상 명시

정확도 예상: S100은 텍스트 직파싱이라 95%+, iG5A는 매핑 테이블 검수 후 100% (매핑 자체가 사람 확인 대상 20건). 비전 모델 경로는 불필요 판단이나, **최종 확정은 사람 승인 후** (TODO_직접할일.md 결정 대기 항목).

## 리스크: 추출 실패 예상 지점

1. **iG5A 7-세그먼트 이미지 코드** (최대 리스크 적중) — 표 어디에도 코드 텍스트가 없음. 통신 챕터 매핑으로 우회하지만, 비트에 없는 항목(로더 이상·브레이크 제어 이상 등)은 코드 부여 불가 → error_codes에서 제외하거나 한글명 키로 수록할지 결정 필요
2. **원인/조치 불릿 분해** — 셀 내 줄바꿈이 문장 중간에서 발생 ("" 불릿 기호 기준 재조립 필요). 잘못 붙이면 causes/actions 오염
3. **S100 물리↔인쇄 페이지 오프셋** (물리 = 인쇄 + 16) — manual_page 인용 기준을 물리 페이지로 통일하지 않으면 인용 검증 실패
4. **다단 표의 행 경계** — S100 일람표에서 분류 셀이 세로 병합 → 분류(severity) 전파 로직 필요
5. **iG5A 표준본 12.1과 트러블슈팅 문서의 항목 불일치 가능성** — 커버리지 비교 결과 트러블슈팅이 원인/조치는 더 풍부하나 항목 수는 표준본 12.1이 기준. 추출 시 두 소스 병합 + 출처 페이지 각각 기록
