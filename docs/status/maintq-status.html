⛔ 무효

4차 평가(2026-08-12)는 튜닝 효과를 판정할 수 없습니다 — 지표가 좋아 보이지만 착시입니다

표면 수치는 인용 83.3% → 100% · 안전 72.2% → 90%로 목표에 닿은 것처럼 보입니다. 그러나 T11~T20 10문항이 실행 실패해 분모에서 빠졌고, 하필 3차의 인용 실패 3건이 전부 T13·T14·T15였습니다. 즉 실패하던 문항이 사라져서 100%가 된 것이지 고쳐져서가 아닙니다 — 완주한 T01~T10은 3차에서도 이미 전부 PASS였습니다. 부품은 오히려 46.7% → 30.0%인데 이 역시 분모(15 → 10)가 달라 비교가 성립하지 않습니다.

판정 — 이 회차는 기록만 하고 개선 근거로 쓰지 않습니다. 좋아 보이는 수치를 그대로 인용하는 것이 이 프로젝트에서 가장 하지 말아야 할 일입니다. 원인은 아래에서 확정·수정됐고, 같은 코드로 다시 돌린 5차(20260812-015934)가 20/20 완주해 3차와 같은 분모를 회복했습니다.
✅ 해결

평가 정지 결함 — 원인 확정 · 수정 완료. 원인은 우리가 넣은 계측이었습니다
