진행 중 — M4 Stage 4

유일한 실비용 실행 단계

평가 파이프라인 자체는 완성됐고, 실 20문항 1회 전체 실행만 남았습니다. 세 차례 시도에서 버그 3건을 발견·수정했고, 네 번째 시도는 환경 문제로 중단된 상태입니다.

fix 1 — judge 무제한 대기

수정완료

환각 judge 호출에 타임아웃이 없어 1차 시도가 60분+ 정지. asyncio.wait_for로 보호 + 타임아웃 시 보수적 fail 처리.

fix 2 — .env 미로드

수정완료

run_eval.py 자신의 프로세스가 .env를 로드하지 않아 S4 문항(T19·T20)만 매번 실패. 모듈 상단 로드 추가.

fix 3 — 이벤트 루프 재개방

수정완료

문항 루프 종료 후 새 동기 클라이언트가 Windows 소켓에서 정지. check_permission_403을 async로 바꿔 같은 루프 안에서 실행.

알려진 문제점

5건 — 코드 결함 아님, 대부분 환경·데이터 게이트
환경

WinError 10014 — Windows 소켓 계층 불안정 (미해결)

새 이벤트 루프 생성·서버 기동 시 간헐적으로 "잘못된 포인터 주소" 오류 발생. 반복된 강제 종료(Stop-Process -Force) 누적 효과로 추정 — 코드 문제 아님.

다음 조치 — 터미널/PC 재시작으로 소켓 상태 리셋 후 run_eval.py --yes 재시도. fix①②③은 회귀로 검증 완료된 상태라 코드는 준비돼 있음.
