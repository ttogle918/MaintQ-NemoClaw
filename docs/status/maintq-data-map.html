발견

대상이 어긋나 있었다

문제

중고설비 매물 16,011건 중 인버터는 4건, 공작기계는 7,048건. 이 시장은 완제품 설비지 부품이 아닙니다. 그런데 확장 범위의 대상이 equipment_id = 인버터였습니다.

11 §1이 처분 서사의 근거로 든 "수명 20~30년 · 신품 납기 수개월~1년"은 공작기계 특성이지 인버터가 아닙니다.

해결

실마리는 이미 데이터 안에 있었다

D68 확정
