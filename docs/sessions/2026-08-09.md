## 결정과 맥락

### D76 — 왜 이게 나왔나

사용자가 *"기능 구현을 싹 한 다음 기능별로 성능을 올리고 싶다. 그러면 input/output·state·DB 를
확정해야 하는 것 아니냐"* 고 물은 데서 시작했다. **평가를 돌리기 직전에 멈춘 게 결과적으로 옳았다.**

구조를 뜯어보니:

- **LLM 은 도구 결과 원본을 단 한 번도 보지 못한다.** `messages = store.history()` 가 매 LLM
  호출마다 갱신되므로 **같은 턴 안에서도** 프로즈 요약만 간다. 실측하니
  `lookup_error_code` 결과에서 `meaning`("과열")·`actions` 가 통째로 사라졌다 —
  `PRESERVE_FIELDS` 화이트리스트에 없어서다.
- **원본은 DB 에도 없다.** `TraceWriter.tool_result()` 가 받는 건
  `{tool,status,summary,elapsed,pages,parts}` 뿐이다. 평가 판정 소스인 `traces` 로
  "도구가 정말 그 값을 줬는지"를 사후 검증할 수 없다 — sprint-3 Stage 4 W-1 이 지적한
  "블록은 있고 숫자는 지어낸" 케이스가 여기서 나온다.
- **같은 뿌리에서 증상이 셋**이었다: `PRESERVE_FIELDS`(이력) · `_pages_from`(D54) ·
  `_parts_from`(D66). 전부 "원본이 없으니 필요한 필드를 하나씩 뽑아 싣는" 화이트리스트다.
  **지표가 늘 때마다 화이트리스트가 하나씩 붙는 구조**였다.

### 핵심 논거 — 실패 방향을 뒤집는다

|---|---|---|

| 도구 16종이 되면 | 샐 표면 2배 | 그대로 |

루프에도 중첩 dict 루프에도 안 걸림). Sprint 6 이 도구를 9종 추가하므로 **그 전에** 고치는 게
이번 순서의 이유다.

### 검토하고 버린 대안

- **① 현행 유지 / ② 화이트리스트만 확장** — 위험이 도구 수에 비례한다
- **③ JSON 문자열을 `role:"user"` 로** — 구조 손실은 풀리지만 도구 결과가 **사용자 발화로
  위장**돼 모델이 오독한다. 제공자들이 tool 프로토콜을 따로 둔 이유가 그것
- **④ 순수 백그라운드 쓰기(배리어 없음)** — 사용자가 "DB 적재는 백그라운드로" 를 요구했으나
  **`run_eval.py` 가 스트림 종료 직후 `GET /trace`** 를 호출한다. 배리어가 없으면 아직 안
  써진 이벤트가 빠진 채 채점돼 **지표가 실행마다 랜덤하게 틀린다.** `traces.seq` 의
  `UNIQUE(session_id, seq)` + `MAX(seq)+1` 이어쓰기도 동시 쓰기와 충돌한다.
  → **큐 + 턴 종료 배리어**로 절충. 요구(비차단)는 지키고 A5 는 "턴 경계에서는 발행=저장"
  으로 약화된 형태로 유지된다

### 축을 나눈 것이 논의의 분기점이었다

사용자의 *"AI 에게서 JSON 으로 받아 자체 처리하고 싶다"* 는 **축 B(LLM → 시스템)** 인데,
실제 병목은 **축 A(도구 결과 → LLM)** 였다. 그리고 **축 B 는 지금 구조가 맞다** —
`unit_price` 는 조회 스냅샷(D31), 인용은 코드 생성, 안전 문구는 상수. LLM 이 JSON 을 만들게
하면 **금액과 페이지를 지어낼 경로가 생긴다.** 환각률 0%·인용률 100% 가 거기 걸려 있다.
구조화 출력이 필요하면 **"판단만 받고 값은 코드가 채우는"** 중간 경로를 쓴다.

## 트러블슈팅

### `LAW_API_OC` — 법제처 에러 메시지가 오진단을 유발한다

- **증상**: 실호출 시 `{"result":"사용자 정보 검증에 실패하였습니다.",
  "msg":"... 서버장비의 IP주소 및 도메인주소를 등록해 주세요"}` (HTTP **200**)
- **1차 진단(틀림)**: 메시지를 그대로 믿고 IP 등록 문제로 판단, 공인 IP 를 뽑아 등록을 권고
- **실제 원인**: `.env` 의 값이 **5자로 잘려 있었다**(`ttogl`). 전체 값 `<LAW_API_OC>` 로 호출하니
  HTTP 200 · 총 3건 정상 반환
- **교훈**: **OC 가 틀려도 "IP 를 등록하라"고 안내한다.** IP 부터 의심하지 말고 **값 길이를
  먼저 확인**할 것. `.env.example` 에 두 실패 문자열과 이 함정을 기록했다
- **부수 수확**: MST 3개 확보 — 조세특례제한법 `280409` · 시행령 `287181` · 시행규칙 `284611`
  (`fetch_laws.py` 가 필요로 하던 값)
