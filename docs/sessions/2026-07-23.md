### `X-User: 김OO` 가 HTTP 헤더로 전송 불가 (SP3)
- **증상**: `UnicodeEncodeError: 'ascii' codec can't encode character '김'`
- **원인**: HTTP 헤더 값은 ASCII(latin-1) 범위. httpx·브라우저 `fetch` 양쪽에서 거부
- **해결**: ASCII 사용자 ID(`tech-01`) + 표시명 서버 매핑 (D36) → 나중에 `users` 테이블로 이관(D41)
- **커밋**: `37d7143`

### 발주 시각이 "9시간 전"으로 표시 (프론트 연동)
- **증상**: 방금 시드한 발주가 9시간 전으로 렌더
- **원인**: SQLite `CURRENT_TIMESTAMP` 는 UTC 인데 타임존 표기가 없어 브라우저가 KST 로 해석.
  더 큰 문제로 `error_history` 는 로컬시간 시드 → **한 DB 에 두 시간 기준**
- **해결**: 저장·전송 UTC 통일, API 는 ISO-8601 `...Z` (D39)
- **커밋**: `74fa886`

### 청크 165개 페이지 유실 (MQ-305)
- **증상**: 없음 — **모든 검사를 통과했다**
- **원인**: `chunks[-2] += chunks.pop()` 에서 `pop()` 이 리스트를 줄인 뒤 `-2` 가 재계산.
  두 청크가 같은 객체를 가리켜 앞부분이 통째로 사라졌다.
  부분 문자열 검사도 멱등성 검사도 통과한다 — **매번 똑같이 틀리기** 때문
- **해결**: "페이지 청크를 idx 순으로 이으면 페이지 텍스트와 정확히 일치" assert 추가
- **커밋**: `3b14c2b`

### 포트 3000·3001·3002 점유
- **증상**: `EADDRINUSE`
- **원인**: 다른 프로젝트(Kkebi 등)가 사용 중
- **해결**: 프론트 3003 / 백엔드 8003 / SP3 8083 고정, CORS 는 3000~3005 범위 + env override
