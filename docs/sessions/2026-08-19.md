### 캐시 강제 차단이 정반대로 작동했다 (최종 리뷰 블로커 C1)
- **증상**: `run_eval` 기본 모드에서 캐시를 끄려 했으나 자식 서버는 캐시로 돌았다
- **원인**: `os.environ.pop(ENV_FLAG)` 로 키를 **비우면**, 자식이 `backend/main.py:39` 의 `load_dotenv(override=False)` 를 도는데 그 규칙이 *"빈 곳만 채운다"* 라 **`.env` 값이 그 자리를 채웠다.** 실제로 꺼진 건 부모의 judge 호출뿐
- **해결**: `pop` 대신 `os.environ[ENV_FLAG] = "off"` 명시 주입 — 값이 있으면 `override=False` 가 덮지 않아 자식까지 살아남는다. 수정 전 자식 `cache_enabled()=True`(버그 재현) → 수정 후 `False` 로 **실측 증명**
- **커밋**: `f7f6ece`
- **이 설계의 원칙("지우지 말고 표식/명시하라")을 정작 내가 어긴 자리였다**

### `UnicodeDecodeError` 가 `OSError` 가 아니다
- **증상**: 손상 캐시 폴백이 인코딩 손상에서만 깨진다
- **원인**: `UnicodeDecodeError` 는 `ValueError` 하위 — `except (OSError, json.JSONDecodeError)` 로 못 잡는다
- **해결**: 세 예외 명시 나열 + 잘못된 UTF-8 바이트 테스트. **커밋**: `58ae8ca`

- **해결**: 빈 델타 미기록(캐시 쪽) + 루프 종료 직후 멱등 재판정(루프 쪽) **둘 다**. **커밋**: `c82a558`

## 트러블슈팅

### 대조군 생존 축이 자명 충족돼 있었다 (Stage 3 리뷰 C1)
- **증상**: 표 경로가 *"앵커 행에 12자 이상 이웃 셀이 있으면 `ACTION_FOUND`"* 였다
- **원인**: 판독 범위의 1차 표는 **조치표가 아니라 트립/보호기능 표**라 조치문 없는 코드에도 항상 긴 설명 셀이 있다(`NMT` `actions=0 desc=53자`·`ALOR` 92자)
- **귀결**: 대조군 전건 통과 → **`READER_BLIND` 원리적 발화 불가** + 결측 25건 **전건 `DISAGREE`**. 1,530원이 무의미해질 뻔했다
- **해결**: 생존 축을 **정본 `actions` 문장 대조**(`action_verified`)로 교체. 대조군은 조치문 원문을 이미 갖고 있어 자명 충족이 구조적으로 불가능해진다. **커밋**: `898d6ae`

### `rowspan` 귀속이 가짜 1:1 을 만들었다 (C2)
- **원인**: `covered = row_index + offset` 이 "앵커 행 = 조치 셀 시작 행"을 가정. 표 끝에서 `covers=1` → `RECOVERABLE`
- **해결**: **셀 정체성**(`any(c is action_cell for c in row)`)으로 세고 `or 1` 폴백 제거. **커밋**: `898d6ae`

### 픽스처가 스스로의 원칙을 어겼다 (재리뷰)
- **증상**: 주석이 *"지어낸 문장 0건 — 지어내면 검사가 자기 자신을 검증한다"* 고 단언했으나 **2건이 합성**이었다
- **원인**: 그 대체가 C1 이 새로 들여온 **반대 방향 위양성**을 가렸다 — `COL` 의 실제 원인문 *"콘덴서를 **교체**할 시기가 되면"* 의 `교체` 가 `ACTION_MARKERS` 에 걸린다
- **해결**: 실제 문장으로 교체해 회귀가 그 위양성을 보게 하고, 단언을 *"예외 2건, 이유는 각각 다르다"* 로 정정

### `.env` 값에 따옴표가 있어 파일럿이 두 번 실패했다
- **원인**: ⓐ CLI 는 `.env` 를 로드하지 않는다(D56 — 로드는 앱 진입점 한 곳) ⓑ 내 파싱이 따옴표를 안 벗겼다
- **해결**: 이번 호출에만 환경 주입(코드 미변경). `normalize_base_url` 이 `"` 로 시작하는 값을 **모델 ID 로 보고 거부한 것은 제 일을 한 것**이다
- **미결**: CLI 로 이 모듈을 쓰려면 매번 환경 주입이 필요하다 — D56 경계 문제라 코드로 안 고쳤다
