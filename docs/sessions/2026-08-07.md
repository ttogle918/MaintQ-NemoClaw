  어느 행에 붙는지 모호해진다.**

## 트러블슈팅

### IE5 코드 추출 불가 — 원인 오진 후 정정

- **증상**: 간이판 `고장표시` 표(p54) 셀이 전부 빈 문자열
- **1차 진단(과했음)**: "간이판은 코드를 못 뽑는다" → **틀렸다.** 전수 재조사 결과
  **간이판에도 코드가 다른 페이지에 텍스트로 있다**(p34·41·45·47·50·51). 못 뽑히는 건
  **p54 고장표시 표의 코드 컬럼 하나뿐**이었다
- **원인**: 해당 표의 코드만 7세그먼트 폰트 **이미지**. p54 는 `chars` 1,041개가 정상
  추출되는데 라틴 토큰이 `DC` 하나뿐 → 코드 문자가 content stream 에 **없음**
- **"다른 PDF 패키지 쓰면 되나?" → 아니다.** pdfplumber·pypdf·PyMuPDF·pdfminer 는 **같은
  content stream** 을 읽는다. 차이는 표 검출·레이아웃 휴리스틱이지 텍스트 존재 여부가
  아니다. **OCR 만 다르고**, 7세그먼트는 오독률이 높아 위험하다
  (2026-08-05 "엉뚱한 에러코드에 붙은 조치" 교훈)
- **해결**: 표준판 확보로 우회 → P29

### `확인불가` 함정 — 결측률 0% 를 믿으면 안 된다

- **증상**: 중진공 CSV 제조년월 결측률이 **0%** 로 나옴
- **원인**: 결측 대신 `확인불가` **문자열**이 채워져 있었다
- **영향**: 그대로 믿고 5,911 대신 16,011 을 분모로 쓰면 **잔가곡선이 통째로 틀어진다**
- **실제 유효 표본**: 연도 5,911(36.9%) · **연도+가격 교집합 5,396(33.7%)**
