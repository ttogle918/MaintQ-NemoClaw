## 결정과 맥락

### DB 재시드가 라이브 Postgres를 안 건드리던 함정
- **계기**: 리허설 잔재 정리하려고 `uv run python data/seed.py --with-error-codes`를 그냥
  돌렸더니 "[완료] ...data\maintq.db"만 찍히고 컨테이너가 실제로 쓰는 Postgres는 그대로였다
- **원인**: `DATABASE_URL`이 대화형 셸 프로필엔 있어도 `uv run` 서브프로세스에는 전달이 안 됨 —
  `data/dbcompat.py`의 `USE_POSTGRES = bool(os.environ.get("DATABASE_URL"))`가 그 프로세스
  안에서 False로 평가됨
- **해결**: `DATABASE_URL=postgresql://... uv run python data/seed.py --with-error-codes`처럼
  인라인으로 명시 — `[대상] Postgres —` 로그로 확인 후 진행

### OpenAI 대체 모델 선정
- **계기**: Elice 크레딧 소진으로 촬영이 막혀 즉시 대체 provider가 필요했다
- **대안 비교**: Gemini Flash($0.30/$2.50)와 가격대를 맞추려면 gpt-4.1-mini($0.40/$1.60)가
  제일 근접, gpt-4o-mini($0.15/$0.60)가 오히려 더 저렴, gpt-4o($2.50/$10)는 4~8배 비쌈
- **결정**: 사용자가 가격보다 도구 호출 안정성을 우선해 **gpt-4o**를 선택. `.env`의
  `OPENAI_API_KEY`가 실은 `ELICE_API_KEY`와 동일한 JWT(가짜)였던 것도 이 과정에서 발견해
  사용자 셸 프로필의 진짜 `sk-proj-...` 키로 교체

### FDS 2FA에서 재등록 대신 결재대기 상태로 멈추기
- **계기**: 시나리오1 촬영 중 FinAllQ 승인 후 `completed` 대신 추가인증 요구로 멈춤 — 원인은
  FDS 오탐이 아니라 "a2a-service 계정 거래이력 없음(첫 거래) + 심야 시간대" 조합이 사유코드
  2개를 동시에 띄워 `REQUIRE_2FA`를 트리거한 것(FinAllQ 세션이 코드로 확인)
- **대안**: TOTP 재등록(`/security` 화면에서 enroll→confirm)해서 완주까지 촬영 가능했다
- **결정**: 사용자가 "귀찮다"며 재등록 대신 **그 상태에서 멈추는 것으로 촬영 종료** — 오히려
  "A2A가 결제까지 전부 자동으로 끝내지 않는다"는 설계 의도를 보여주는 자연스러운 지점으로 재해석
