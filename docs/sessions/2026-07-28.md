- **대안**: ① 도구 원문 payload 전체를 traces 에 저장 — 대화 전문 축적(D41 이 token 에서 막은

  환각 페이지를 못 잡는 채로 홍보하게 되므로 기각.
- **경계 설계**: strict/degraded 는 **`pages` 키 존재**로 가른다. 생산자가 있는데 근거가 비면

  회귀가 거짓 신호를 낸다. 근거 집합은 `pages ∪ 합성 manual_page ∪ chunks[*].page` 합산
  (reviewer 참고 지적으로 결정문에 명기).
