# 스프린트 로그

`/sprint N` → `/stage M` → `/done` 워크플로우의 산출물이 쌓이는 곳.

| 파일 | 언제 생기나 | 내용 |
|---|---|---|
| `sprint-{N}.md` | `/sprint N` | 스테이지 계획 + PM·tool-builder 평가 + 스테이지별 완료 기록 |
| `sprint-{N}-wip.md` | `/checkpoint` | 중단 시점의 진행 상태 (다음 세션 재개용) |

세션 단위 로그는 `docs/sessions/` 에 쌓인다 (`/done`).

## 태스크 ID

`MQ-{스프린트}{순번}` — 예: Sprint 2의 첫 태스크는 `MQ-201`.

## 이 폴더가 설계 문서가 아닌 이유

`docs/00~10` 은 **무엇을 왜 만드는가**(계약·결정)를 담는다. 여기는 **언제 어떻게 만들었는가**(실행 기록)다.
설계가 바뀌면 `10_DECISIONS.md` 에 D를 추가하는 게 먼저고, 스프린트 로그는 그 뒤를 따른다.
