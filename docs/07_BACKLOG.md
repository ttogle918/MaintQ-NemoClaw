# 백로그 (v2 이후)

MVP에서 의도적으로 제외한 기능. 우선순위 순.

| P | 기능 | 설명 | 미리 확보해둔 것 |
|---|---|---|---|
| P1 | 사진 진단 | HMI/에러 표시부 사진 업로드 → 비전 모델로 코드 인식 → 진단 파이프라인 진입 | 화면 A 입력창에 📷 버튼 자리, 참고: 데이콘 한양대×현대엔지비 제조 AI Agent 해커톤(멀티모달) |
| P2 | 긴급도 기반 공급사 추천 | 다운타임 비용 입력 → "빠른 공급사 vs 싼 공급사" 추천 로직 | 화면 B 공급사 비교 카드에 추천 슬롯, supplier_parts에 lead_days/unit_price 이미 존재 |
| P3 | 승인 요청 알림 | 발주 요청(draft→pending) 시 팀장에게 슬랙/이메일 웹훅 알림. 실사용 전환의 필수 조각 — 팀장이 앱을 안 열어도 결재가 시작됨 | po_drafts 상태 전이 지점에 훅 포인트, urgency 뱃지 |
| P4 | 다국어 현장 모드 | 외국인 현장 작업자(베트남어·네팔어·인도네시아어 등) 대상 진단 안내 번역. 한국 중소제조 현장의 실제 인력 구성 반영 — 안전 경고의 다국어화는 안전 가치와 직결 | 안전 경고가 구조화 필드로 분리돼 있어 번역 대상 특정 용이 |
| P5 | 감사 로그 (Audit Trail) | 누가 언제 무엇을 요청/승인/반려했는지 불변 기록. B2B 도입 시 반드시 나오는 요구사항 | po_drafts의 requested_by/decided_by/reason이 이미 원형 |
| P6 | 발주서 내보내기 | 승인된 발주서를 PDF/이메일로 공급사에 발송하는 마지막 마일 | suppliers.contact 컬럼 |
| P7 | 모델 자동 식별 고도화 | 형명(nameplate) 텍스트/사진으로 모델 자동 판별, 모호 시 확인 질문 | equipment 테이블의 model 컬럼 |
| P8 | 음성 인터페이스 | 현장 작업자(장갑 착용) 대상 STT/TTS | 강의자료 「음성으로 제어하는 MCP」 참고 |
| P9 | 예산/승인 한도 체크 | 금액 구간별 승인 단계 차등 (팀장→부장) | po_drafts.state 확장으로 대응 가능 |
| P10 | 예지보전 연계 | 반복 감지 데이터 축적 → 고장 예측 모델의 입력으로 | error_history 스키마가 학습 데이터 포맷 겸용 |
| P11 | 기종 확장 | iS7, G100 등 추가 | error_codes 적재 + enum 확장만으로 가능 |
| P12 | CMMS 연동 | 정비 이력 자동 기록 (양방향) | MCP 서버 교체 구조(10_DECISIONS D15) |
| P13 | 매뉴얼 버전 워처 | LS 자료실 주기 체크 → 신버전 감지 시 알림 + 다운로드·재추출·diff 리포트 자동화 | data/raw/manifest.json의 버전·해시 체계가 이미 감지 기반 (D19) |

## 아이디어 주차장 (미분류)

- 발주 이력 기반 소모성 부품 자동 재주문 제안 (안전재고 하회 시 선제 알림)
- 점검 체크리스트 완료 체크 → 정비 리포트 자동 생성
- 팀장 화면 주간 요약 (반복 고장 Top3, 발주 지출 합계)
