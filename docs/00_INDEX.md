# MaintQ 문서 인덱스

**3줄 요약:** MaintQ는 인버터/PLC 에러 진단→부품 특정→재고·견적→발주 승인을 하나의 대화로 잇는 B2B 보전 에이전트다. Q 시리즈 3번째로, 주제는 도구 오케스트레이션(FinAllQ·InsuQ가 검색 깊이였다면). AI는 발주 초안까지만, 확정은 사람이 한다.

| [02_SCENARIOS](02_SCENARIOS.md) | S1(순차)·S2(분기)·S3(이력+가드레일)·S4(실패 처리) + 도구 시퀀스 | 기능 구현 전 "이게 어느 시나리오에 복무하나" 확인 |
