  발주서 초안 카드(품목/수량/공급사/단가 + "팀장 승인 요청" 버튼만 — 확정 버튼 없음)

  텍스트 스트림 중간에 삽입되므로, 말풍선 흐름 사이에 끼어들어도 자연스러운 형태로

- [ ] trace 패널이 채팅보다 시각적으로 죽지 않았는지
- [ ] 인용 페이지 칩이 모든 진단 말풍선에 들어갔는지
- [ ] 인용 칩이 **인쇄 페이지 우선 + PDF 병기** 형식인지 (`S100 매뉴얼 p.400 (PDF p.416)` — D32).

- [ ] 안전 경고 블록이 스크롤 중에도 눈에 걸리는 강도인지

- [ ] 발주 보류 블록이 발주 카드와 시각적으로 구분되는지 (`po_card` variant:`hold`, D35)

### 목업용 예시 데이터 (⚠ 문장은 가짜다 — D144)

매뉴얼 원문 문장을 디자인 도구에 넣지 않는다(재배포). **코드·에러명·페이지·구역은 사실**이라 그대로 쓰고,
원인·조치 문장은 **형태만 맞춘 가짜**로 쓴다.

| 코드 | 에러명(원문) | 구역 | 페이지 | 원인(가짜 예시, 영문) | 한국어 정규화(가짜 예시) | 플래그 |
|---|---|---|---|---|---|---|
| `oH` | Heatsink Overheat | 고장 | p.110 | Cooling path is blocked. | 냉각 경로가 막혔다. | — |
| `oH` | Heatsink Overheat | 알람 | p.119 | Ambient temperature is high. | 주위 온도가 높다. | 중복 코드 |
| `GF` | Ground Fault | 고장 | p.108 | Output cable insulation is damaged. | 출력 케이블 절연이 손상됐다. | — |
| `EF3` | External Fault (Terminal Sx) | 고장 | p.108 | External device signaled a fault. | 외부 기기가 고장 신호를 보냈다. | 원표기 `EF1 to EF7` |
| `CE` | Run at H5-34 (CE Go-To-Freq) | 알람 | p.116 | Communication wiring is incorrect. | 통신 배선이 잘못됐다. | 같은 구역 이름 중복 |
